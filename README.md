# ASCII Art Web Page 🎨

This project is a simple web application that converts input text into ASCII-style art using a browser interface.

## 🚀 Features

* Convert text into ASCII art
* Simple and clean user interface
* Fast and responsive output

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

* index.html → Main webpage
* style.css → Styling
* script.js → Logic (if used)

## ▶️ How to Run

1. Download or clone the repository
2. Open the folder in your own IDE run to use it

## 📌 Future Improvements

* Image to ASCII conversion
* Custom font styles
* Download ASCII output
